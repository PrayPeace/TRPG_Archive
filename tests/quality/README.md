# AI 품질 시험 자료

요약·정리·다음 할 일을 만드는 AI가 "틀리게 적는 일"을 얼마나 하는지 재는 자료입니다.

**지금까지 실제 Claude로 돌린 적이 없습니다.** 저장소의 자동 시험(`tests/t_quality.js`)은 채점 도구가 맞게 세는지만 봅니다. 사람이 쓴 "잘한 답"과 "틀린 답"을 넣어 본 것이고, AI 품질 점수가 아닙니다.

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `fixture.js` | 대본(세션 1, 세션 2), 마스터 전용 자료(`keeperOnly`), 정답표(`key`) |
| `score.js` | 정답표와 비교해 숫자를 내는 채점 도구 |
| `run-real.js` | 연습 방에 대본을 넣고 실제 요약·추천을 받아 채점까지 하는 도구 |

## 대본에 넣은 함정

- 농담("불 지르고 가자"), 가정("만약에 집사를 묶으면"), 게임 밖 잡담(다음 주 약속)
- 판정 성공과 실패가 섞여 있음 (심리학 실패, 도서관 이용 실패, 관찰력 성공, 듣기 성공)
- NPC의 거짓말일 수 있는 주장 ("서재에 들어간 적이 없습니다")
- 플레이어의 추측 ("내 생각엔 집사가 범인")
- 장면 전환 (현관 → 서재 → 지하실 계단, 지나가며 말만 한 장소도 있음)
- 받아쓰기 인식 오류 (집싸, 도서간, 벽날로)
- 복구된 말 표시 "(확정 전)"과 "※ 받아쓰기 끊김 …" 안내 줄
- 세션 1에서 이미 끝난 일 (다시 추천하면 안 됨)
- 마스터 전용 자료에만 있는 사실 (공용 화면에 나오면 누출)

## 재는 숫자

| 항목 | 합격선(제안) |
|---|---|
| 단서 누락률 | 8개 중 1개 이하 |
| 지어낸 사실·농담·가정을 사건으로 적음 | 0 |
| 판정 성공/실패 뒤바뀜 | 0 |
| NPC 주장을 사실처럼 적음 | 0 |
| 이미 끝난 일을 다시 추천 | 0 |
| 마스터 자료 누출 | 0 |
| 판정 빠짐, 추측을 사실처럼 적음, 추천에 빠진 것, 하기로 한 일이 맨 위에 없음, 받아쓰기 안내를 요약에 옮김, 잘못 들린 낱말을 그대로 적음, 지금 장면이 맞음 | 숫자만 기록 |

정규식으로 가릴 수 없는 것(문장이 자연스러운지, 근거 발언이 맞는지 등)은 채점 끝에 "사람이 읽고 확인할 것" 목록으로 나옵니다.

## 실제로 재는 순서 (PC, 테스트용 채널)

1. 테스트용 채널 마스터 탭의 시나리오 자료에 `fixture.js`의 `keeperOnly` 글을 올립니다. 안 올리면 누출 항목은 "확인 못 함"입니다.
2. 명령 창에서 실행합니다. 방 이름에 "테스트"나 "연습"이 없으면 도구가 멈춥니다.
   ```
   ROOM_URL="테스트용 채널 /exec 주소" ROOM_PW="방 비밀번호" KEEPER_PW="마스터 비밀번호" node tests/quality/run-real.js
   ```
3. 화면에 나온 숫자와 `quality-out.json`을 보관합니다. 같은 대본으로 3번 돌려 숫자가 흔들리는 폭도 봅니다.
4. "사람이 읽고 확인할 것"을 직접 읽고 예/아니오를 적습니다.

- 기존 기록을 지우지 않고 뒤에 이어 붙입니다. 세션이 하나 늘어납니다.
- Claude 호출은 한 번 돌릴 때 요약 2~4번, 정리, 추천 1번 정도입니다. 요금이 듭니다.
- 운영 방(질긴 결속)에서는 돌리지 마세요.

## 한계

- 대본이 하나뿐이라 이 숫자가 좋아도 다른 시나리오에서 같다는 보장은 없습니다.
- 정답표는 낱말이 들어 있는지를 보는 방식이라, 뜻은 틀렸는데 낱말만 맞는 문장은 놓칩니다. 그래서 사람 확인 목록이 따로 있습니다.
